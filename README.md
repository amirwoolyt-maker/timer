# راهیار

نسخهٔ Flutter اپلیکیشن برنامه‌ریزی درس و زندگی روزانه با رابط فارسی راست‌چین و تم «Cosmic Emerald».

## اجرا

```bash
flutter pub get
dart run build_runner build
flutter run -d chrome
```

برای خروجی وب:

```bash
flutter build web --release
```

پایگاه‌دادهٔ Drift روی موبایل از SQLite بومی و روی وب از `sqlite3.wasm` و `drift_worker.js` استفاده می‌کند. وب باید با هدرهای زیر سرو شود تا ذخیره‌سازی اشتراکی WASM فعال بماند:

```text
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

فایل `Caddyfile` نمونهٔ میزبانی خروجی `build/web` را دارد.

## ساختار

- `lib/core`: تم، وضعیت زبان/ظاهر و قالب‌بندی تاریخ و اعداد
- `lib/data`: جداول Drift، مهاجرت پایگاه‌داده و Providerهای Riverpod
- `lib/features`: صفحه‌های کارها، یادداشت‌ها، تایمر، همراهان و گرید ابزارهای بیشتر
- `assets/fonts`: وزن‌های فونت Vazirmatn

## قابلیت‌های پیاده‌سازی‌شده

کارها با اولویت، دسته، زمان، تکمیل و جستجو؛ یادداشت‌های آفلاین با سقف ۱۵ مورد؛ تایمر پومودورو و کرنومتر؛ تقویم جلالی؛ پروژه‌ها؛ داشبورد آمار؛ ۱۶ گزینهٔ بخش بیشتر؛ حالت تمرکز با تأیید خروج؛ سطل زباله با بازیابی و حذف دائمی؛ کتاب‌های شخصی؛ اجتماع آفلاین؛ و آلارم با چالش ضرب، شمارش پاسخ‌های نادرست و قفل پس از شش خطا.

آلارم داخل برنامه در چرخهٔ اجرا بررسی می‌شود. زنگ و اجرای پایدار در پس‌زمینهٔ سیستم‌عامل به سرویس بومی و مجوزهای جداگانهٔ Android/iOS نیاز دارد. قابلیت لیگ، چت، اتاق گروهی، منابع، رتبه‌بندی دانشگاه، یادآور مکان و چرخه در این نسخه صفحه‌های نمونه‌اند و به سرویس یا مجوز بومی وصل نیستند؛ پست‌های اجتماعی محلی ذخیره می‌شوند و همگام‌سازی شبکه‌ای ندارند.

ساخت Android در این محیط به‌دلیل نبود Android SDK قابل اجرا نبود. ساخت iOS باید روی macOS انجام شود.
